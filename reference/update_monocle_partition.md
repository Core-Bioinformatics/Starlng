# Update the partition of the Monocle object

This function updates the partition of the Monocle object, which is used
for tasks such as trajectory analysis.

## Usage

``` r
update_monocle_partition(mon_obj, new_partition)
```

## Arguments

- mon_obj:

  The Monocle object.

- new_partition:

  The new partition to be updated.

## Value

The Monocle object with the updated partition.
