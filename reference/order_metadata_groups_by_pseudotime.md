# Order Metadata Groups by Pseudotime

Orders categorical metadata levels by their median pseudotime value.

## Usage

``` r
order_metadata_groups_by_pseudotime(metadata_value, pseudotime)
```

## Arguments

- metadata_value:

  A vector with categorical metadata values.

- pseudotime:

  A numeric vector with pseudotime values.

## Value

A character vector of metadata levels ordered by median pseudotime.
