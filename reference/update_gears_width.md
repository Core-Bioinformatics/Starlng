# Server - Gear Width

Creates the backend interface that dynamically updates the width of the
gear settings window inside the Starlng Shiny application.

## Usage

``` r
update_gears_width(session)
```

## Arguments

- session:

  The shiny session object used to update the UI elements.

## Note

This function is a shiny module function and should be used in the
context of the app created using the `starlng_write_app` function.
